# Sistema Bibliotecário

Um sistema simples de gerenciamento de biblioteca desenvolvido em Python, utilizando um arquivo CSV para armazenar os livros cadastrados.

O programa permite: Cadastrar, Listar, Buscar, Ordenar, Emprestar e Devolver livros, e consulta o status geral da biblioteca.

## Sumário de Funções

**PRINT 1** Cadastrar novos livros
**PRINT 2** Listar todos os livros cadastrados
**PRINT 3** Buscar livros por título ou autor
**PRINT 4** Ordenar livros por título, autor ou ano
**PRINT 5** Registrar empréstimos
**PRINT 6** Registrar devoluções
**PRINT 7** Consultar a quantidade de livros disponíveis e emprestados
**PRINT 0** Salvar os dados automaticamente em um arquivo CSV

## Tecnologias utilizadas

* Python 3
* Biblioteca "csv"
* Biblioteca "os"
* Arquivo ".csv" para armazenamento dos dados

## Estrutura dos dados

**Campo**  | **Descrição**                 
"Título"   | Título do livro          
"Autor"    |  Autor do livro           
"Ano"      |  Ano de publicação        
"ISNB"     |  ISBN do livro            
"Status"   |  Disponibilidade do livro 

Status:
* "Disponível"
* "Emprestado"
