# Sumário de funções

-- PRINT 1 -- **Cadastrar Livro:** Registra um novo livro com título, autor e ano (gerando um ISBN automático).\n
-- PRINT 2 -- **Emprestar Livro:** Altera o status do livro para ("emprestado").\n
-- PRINT 3 -- **Devolver Livro:** Altera o status do livro para ("Disponível").\n
-- PRINT 4 -- **Listar Livros:** Exibe todos os livros cadastrados na biblioteca.\n
-- PRINT 5 -- **Buscar Livro:** A busca é feita por ordem de título ou autor.\n
-- PRINT 6 -- **Ordenar Livros:** A ordenagem é feita por título, autor ou ano.\n
