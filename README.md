# Sumário de funções

-- PRINT 1 -- **Cadastrar Livro:** Registra um novo livro com título, autor e ano (gerando um ISBN automático).
-- PRINT 2 -- **Emprestar Livro:** Altera o status do livro para ("emprestado").
-- PRINT 3 -- **Devolver Livro:** Altera o status do livro para ("Disponível").
-- PRINT 4 -- **Listar Livros:** Exibe todos os livros cadastrados na biblioteca.
-- PRINT 5 -- **Buscar Livro:** A busca é feita por ordem de título ou autor.
-- PRINT 6 -- **Ordenar Livros:** A ordenagem é feita por título, autor ou ano.
